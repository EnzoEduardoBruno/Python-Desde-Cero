# Python Desde Cero 🐍

Bienvenido a **Python Desde Cero**, un curso pensado para aprender programación desde las bases hasta Programación Orientada a Objetos (POO) y conceptos utilizados en proyectos reales.

Este repositorio está diseñado especialmente para personas que:

* nunca programaron
* recién empiezan
* quieren aprender lógica
* quieren practicar ejercicios reales
* buscan construir una base sólida en programación

No importa si empezás desde cero absoluto.

La idea de este curso es avanzar paso a paso, entendiendo realmente cómo funciona la programación.

---

# 🎯 Objetivo del curso

El objetivo principal es que puedas:

✅ aprender lógica de programación

✅ resolver problemas usando código

✅ entender programación secuencial

✅ dominar Python desde cero

✅ aprender Programación Orientada a Objetos

✅ crear proyectos reales

✅ practicar con ejercicios y desafíos

✅ desarrollar pensamiento computacional

---

# 🧠 ¿Qué vamos a aprender?

El curso está dividido en módulos progresivos.

Primero veremos programación secuencial, que es la base de toda la programación.

Luego avanzaremos hacia Programación Orientada a Objetos (POO) y finalmente veremos herramientas y conceptos utilizados en proyectos reales y entornos profesionales.

# ✍ ¿Dónde tengo que escribir el código?

Todos los ejercicios se resuelven dentro del archivo:

```text
practica.py
```

Cada ejercicio ya tiene una función creada.

Ejemplo:

```python
def ejercicio_1():
    pass
```

La palabra:

```python
pass
```

significa que la función todavía está vacía.

Tu trabajo será:

* borrar `pass`
* escribir tu solución debajo
* usar `return`
* guardar el archivo

---

# ✅ Ejemplo

Si el ejercicio pide retornar:

```text
Hola mundo
```

deberías escribir:

```python
def ejercicio_1():
    return "Hola mundo"
```

# 🚀 ¿Cómo pruebo si está bien?

2. Abrir la terminal
