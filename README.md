# Python Desde Cero 🐍

Bienvenido a **Python Desde Cero**, un curso pensado para aprender programación desde las bases hasta Programación Orientada a Objetos (POO) y conceptos utilizados en proyectos reales.

Este repositorio está diseñado especialmente para personas que:

* nunca programaron
* recién empiezan
* quieren aprender lógica
* quieren practicar ejercicios reales
* buscan construir una base sólida en programación

No importa si empezás desde cero absoluto.
La idea de este curso es avanzar paso a paso, entendiendo realmente cómo funciona la programación.

---

# 🎯 Objetivo del curso

El objetivo principal es que puedas:

✅ aprender lógica de programación<br>
✅ resolver problemas usando código<br>
✅ entender programación secuencial<br>

✅ aprender Programación Orientada a Objetos<br>

✅ desarrollar pensamiento computacional

# ✍ ¿Dónde tengo que escribir el código?

Todos los ejercicios de este módulo se resuelven dentro del archivo:

```text id="9jlwm4"
practica.py
```

Cada ejercicio ya tiene una función creada.

Ejemplo:

```python id="jlwmc5"
def ejercicio_1():
    pass
```

La palabra:

```python id="jlwmhq"
pass
```

significa que la función todavía está vacía.

Tu trabajo será:

* borrar `pass`
* escribir tu solución debajo

---

# ✅ Ejemplo

Si el ejercicio pide retornar:

```text id="jlwmvn"
Hola mundo
```

deberías escribir:

```python id="8jlwm2"
def ejercicio_1():
    return "Hola mundo"
```
