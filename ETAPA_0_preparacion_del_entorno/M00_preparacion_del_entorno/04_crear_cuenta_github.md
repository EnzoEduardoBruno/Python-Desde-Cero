# ☁️ 04 - Crear cuenta GitHub

GitHub es una plataforma que nos permite almacenar nuestros proyectos en internet.

Durante este curso lo utilizaremos para:

* guardar ejercicios
* compartir proyectos
* hacer copias de seguridad
* construir un portfolio
* colaborar con otras personas

---

# 🌎 Ingresar a GitHub

Abrir el sitio oficial:

https://github.com/

Hacer clic en:

```text
Sign up
```

---

# 📝 Crear la cuenta

Completar:

```text
Email

Password

Username
```

Ejemplo:

```text
Email:

juan@gmail.com


Username:

juanperez


Password:

********
```

Elegir un nombre de usuario fácil de recordar.

⚠ IMPORTANTE:

El nombre de usuario formará parte de la URL de tus proyectos.

Ejemplo:

```text
https://github.com/juanperez
```

---

# 📧 Verificar el correo electrónico

GitHub enviará un correo de confirmación.

Abrir el email y hacer clic en:

```text
Verify email address
```

Una vez verificada la cuenta, ya podrás utilizar GitHub.

---

# 🚀 Primer inicio

Al ingresar verás una pantalla similar a:

```text
Repositories

Projects

Issues

Pull Requests
```

---

# 📌 ¿Qué es un repositorio?

Un repositorio es una carpeta almacenada en GitHub.

Puede contener:

* código fuente
* imágenes
* documentación
* archivos markdown
* proyectos completos

Ejemplo:

```text
Python-Desde-Cero/
```

Dentro:

```text
README.md

ETAPA_0_preparacion_del_entorno/

ETAPA_1_programacion_secuencial/

ETAPA_2_programacion_orientada_a_objetos/
```

---

# 👤 Configurar perfil

Ir a:

```text
Settings

→ Public profile
```

Podés agregar:

* foto
* nombre
* ubicación
* biografía
* sitio web
* redes sociales

Esto ayuda a construir un portfolio profesional.

---

# 📌 Perfil público

Tu perfil tendrá una dirección similar a:

```text
https://github.com/TU_USUARIO
```

Desde allí otras personas podrán ver:

* tus repositorios públicos
* tus proyectos
* tus contribuciones
* tu actividad

---

# ⚠ Problemas frecuentes

## El nombre de usuario ya existe

GitHub mostrará un mensaje indicando que el usuario está ocupado.

### Solución

Probar con:

```text
nombre_apellido

nombre123

nombre-dev

nombre-programador
```

---

## No llega el correo de verificación

Revisar:

* Bandeja principal.
* Correo no deseado (Spam).
* Promociones.

Si no aparece, solicitar nuevamente el envío.

---

# 🎯 Objetivo

Si llegaste hasta acá deberías tener:

✅ Cuenta de GitHub creada.

✅ Correo electrónico verificado.

✅ Perfil accesible desde:

```text
https://github.com/TU_USUARIO
```
