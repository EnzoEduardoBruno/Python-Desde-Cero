# 🐍 08 - Primer programa

¡Llegó el momento de escribir nuestro primer programa en Python!

Vamos a crear el clásico:

```text
Hola mundo
```

---

# 📁 Crear un archivo

Abrir VS Code.

Crear un nuevo archivo llamado:

```text
hola.py
```

---

# ✍ Escribir el código

Dentro del archivo escribir:

```python
print("Hola mundo")
```

Guardar el archivo con:

```text
Ctrl + S
```

---

# ▶ Ejecutar el programa

Abrir la terminal:

```text
Ctrl + Ñ
```

o:

```text
Terminal

→ New Terminal
```

Escribir:

```bash
python hola.py
```

Resultado esperado:

```text
Hola mundo
```

---

# 📌 ¿Qué hace `print()`?

La función:

```python
print()
```

permite mostrar información por pantalla.

Ejemplo:

```python
print("Hola")

print("Python")

print(123)
```

Resultado:

```text
Hola

Python

123
```

---

# 🧪 Más ejemplos

Mostrar tu nombre:

```python
print("Juan")
```

Resultado:

```text
Juan
```

---

Mostrar una edad:

```python
print(25)
```

Resultado:

```text
25
```

---

Mostrar una suma:

```python
print(10 + 5)
```

Resultado:

```text
15
```

---

# ▶ Ejecutar desde Code Runner

Si instalaste la extensión **Code Runner**, podés ejecutar el archivo haciendo clic en:

```text
▶ Run Code
```

ubicado en la esquina superior derecha.

También podés usar:

```text
Ctrl + Alt + N
```

---

# ⚠ Problemas frecuentes

## No encuentra el archivo

Ejemplo:

```text
python: can't open file 'hola.py'
```

Esto ocurre porque la terminal no está ubicada en la carpeta correcta.

### Solución

Verificar que estés en la carpeta donde se encuentra:

```text
hola.py
```

---

## El comando `python` no funciona

Ejemplo:

```text
'python' no se reconoce como un comando interno o externo
```

Volver a:

```text
01_instalar_python.md
```

y verificar la instalación.

---

## Se abre una terminal nueva cada vez

Esto puede ocurrir con Code Runner.

Más adelante configuraremos:

```text
settings.json
```

para reutilizar siempre la misma terminal.
